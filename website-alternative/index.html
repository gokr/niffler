Small harness.
Real batteries.

Niffler is as simple and fast to drive as the leanest coding agents — cache-stable prompts, a tiny toolset, measured low token use. But it also has sub-agents, background processes, a permission gate and a unique component model.

01 Fast & cache-effective

Cheap turns,
reported — not promised.

The prompt prefix is frozen for the conversation's lifetime, so provider caches stay hot. The direct toolset stays deliberately tiny; every other capability is one discover/invoke away and arrives as history, never prompt bloat. Fewer tokens per turn, quicker round trips — and the numbers are measured in bench/ against pi, opencode and claudecode, not asserted.

02 Batteries included

What the minimal ones
make you go without.

Sub-agents

Delegate and walk away — a background child job runs, and when it settles it wakes your conversation with the result. Steer, continue or fork it later.

Background processes

Servers, watchers and builds run under the harness: start, poll, kill. No second terminal, no tmux discipline.

Permission gate

A tool can ask first. You answer y/N per call — and with no human reachable, the call is denied. Fail closed, never silently allowed.

Any language

Components are plain processes: Nim, Go, TypeScript — or a shell script with no SDK at all. The language is a preference.

04 Unix-style architecture

Small programs,
one wire.

Every capability is a separate process that does one thing — its own lifecycle, its own failures, isolated from the agent's mind. One wire connects them all: JSON envelopes over NATS. So the agent can write, compile and spawn a new tool mid-conversation, and teardown is just exit(). The OS is the disposer.

05 Install

Two minutes in.

terminal 
git clone https://github.com/gokr/niffler.git && cd niffler
make setup && make build
cp .env.example .env   # add a model API key
make install-tui       # the terminal client (a plugin)
niffler-tui            # boots the harness on demand

Needs Nim 2.2.12+ and Go. The desktop UI installs the same way: make install-ui. Full story in the manual ↗.

Small by default. It builds the rest.
