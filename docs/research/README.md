shipped. Not operating documentation — for that, see
[../MANUAL.md](../MANUAL.md) and [../ARCHITECTURE.md](../ARCHITECTURE.md).

| [OPENHANDS.md](OPENHANDS.md) | Steal list (2026-09-13) from OpenHands Agent Canvas (`28464621d`, frontend-only checkout): per-conversation cost meters and budgets, a distinct `stuck` terminal state, the `/goal` completion loop, LLM compaction with a manual trigger, `PreToolUse`-style blocking hooks, typed tool visualizers + event grouping, client tools (the UI as tool executor), approval risk classes, git-control-bar prompt macros, MCP OAuth2/health verdicts, worktree-per-conversation, schema-driven settings, key-gated remote access (`--public` + one ingress port), and machine-enforced architecture guard tests; plus the four-repo split, REST control plane and settings-blob protocol as explicit non-steals |
| [SUBAGENTS.md](SUBAGENTS.md) | Comparison + gap list (2026-09-14): Niffler's `agent` component vs DSH's subagent subsystem, tool by tool against the spawn/send/wait/list/interrupt baseline. Niffler leads on cancellation depth, durable job records with lazy restart reconciliation, process isolation and human-routed child approvals; it is behind on **continuation** (no second turn into an existing child), **fork** (children always start empty), a **settlement notice into the parent's turn stream** (`ev.agent.done` reaches only UIs today), `list_agents`, and a configurable depth cap. All three headline gaps are append-only for the prompt prefix; effort 2–3 d / 2 d / ≤1 d. Non-steals: the provider registry, in-process children, approvals-pinned-to-`never` |

Per-phase design, contract tests, implementation notes ("found while building it"), and open questions with recorded resolutions |
