A harness that builds
itself out — mid-conversation.

Niffler is a minimal, self-extending agent harness. Components are processes, the bus is NATS, and the agent writes, compiles and spawns its own tools while you talk to it.

make up github →
nimgonatswailssvelte 5
gokr@dev: ~/niffler

$ make up

build core + components + desktop UI · ensure bus + core · open UI

→ spawning nats-server on 127.0.0.1:4222

→ core listening on svc.core.call

→ catalog: bash v0.1.0, builder v0.1.0, store v0.1.0, llm-openai v0.1.0

$ ▌

# why

01 processes, not plugins

No dlopen, no ABI borders, no image rot. A component is a process — teardown is exit(), and the OS is the perfect disposer. A crash never takes the harness down.

02 one protocol

Core speaks exactly one wire format: JSON envelopes over NATS. The codec is ~200 lines and pure std/json — SDKs in Nim, Go, or whatever you port next.

03 self-extension

The agent writes source → calls builder.build → calls core.spawn → the tool is live. Adding a capability is a tool call, and the LLM does it to itself mid-conversation.

04 persistence of shape

Capabilities survive restarts: spawned components are recorded in the store and restored on boot. The repo is the snapshot, var/ is disposable.

  proc weather(city: string): JsonNode =
    ## Current weather for a city
    ## - city: the city name
→
build 
builder.build {
  lang: "nim",
  source: ... }
→
spawn 
core.spawn {
  name: "weather",
  binary: ... }
→
call 
{"tool": "weather",
 "args": {"city": "Berlin"}}

# one wire to rule them

envelope.json 
{
  "v": 1,
  "id": "01J…",
  "op": "call",
  "svc": "bash",
  "tool": "exec",
  "args": { "cmd": "uname -a" },
  "meta": { "sessionId": "s-01J…" }
}

core → svc.core.call, components → svc.<name>.call,
events on ev.*. that's the whole bus contract.
